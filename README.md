# Step Analyzer — DDR読譜トレーナー

DDR(4パネル)の譜面の一部をURLで共有し、**左右どちらの足でどのパネルを踏むべきか**を可視化するWebアプリです。

## 機能

- **譜面描画** — StepMania(SM/SSC)形式のノートデータを貼り付けると、4th/8th/16th…を色分けした譜面として描画
- **足割り解析** — 交互踏みを基本としたアルゴリズムで各ノートにL/Rを自動割り当て
  - 縦連(同一パネル連打)は同じ足
  - ジャンプは移動距離・交差ペナルティ最小の割り当て
  - 交差(体を捻る)箇所には「交差」マークを表示(180度捻り譜面もそのまま可視化される)
- **足の手動指定** — ノートを選んで「この足で踏む」を指定すると、そこを起点に以降を再計算。指定はURLの `f=` パラメータに保存され共有可能
- **パネルビュー + 自動再生** — 4パネル上の足の位置をステップ実行/BPM同期の自動再生(0.5×/0.75×/1×)で確認
- **GUIノーツ編集** — 編集モードでグリッドをタップしてノーツを追加/削除(4〜24分の配置解像度を選択可)。編集結果は即URLに反映
- **モバイル最適化 + PWA** — スマホ縦持ちで譜面とパネルビューを同時表示。ホーム画面に追加するとスタンドアロンアプリとして起動
- **動的OGP画像** — 生成されたURLをXなどに貼ると、その譜面のプレビュー画像(足指定反映済み)が自動で展開されるので、譜面についての議論がしやすい

## URL形式

譜面データはクエリパラメータに直接載せます(URLセーフな文字のみなのでエンコード不要):

```
/?n=<小節1>-<小節2>-...&t=<タイトル>&b=<BPM>&f=<足指定>
/?d=<圧縮データ>&t=<タイトル>&b=<BPM>&f=<足指定>
```

- `n=` は生データ。各小節は「1行4文字のノート行」を改行なしで連結した文字列(`0`=なし, `1`=タップ, `2`=フリーズ開始, `3`=フリーズ終了, `4`=ロール開始, `M`=地雷)。`MMMM` の行はショックアロー(踏んではいけない全パネル電撃)として描画される
- `b=` はBPM。定数 (`b=180`) または ソフラン (`b=130,64:650,96:130` — 先頭が初期BPM、以降 `拍:BPM`)。`s=` は停止 (`s=64:0.5` — `拍:秒`)。拍はSMの `#BPMS`/`#STOPS` と同じ0起点ビート。SMファイル全体をテキスト入力に貼ると自動で取り込まれる
- `d=` は圧縮データ: `base64url(deflate-raw(n形式文字列))`。アプリの「URLをコピー」は短くなる方を自動選択する(長い譜面ほど劇的に短くなる)。`n` / `d` はどちらも受け付ける
- `f=` は足の手動指定。`<tick><L|R>` を `-` 区切り(tickは1ビート=48の整数位置。例: `f=48L-96R`)
- `hs=` はハイスピ(縦縮尺、0.5〜3)、`sp=` は再生速度(0.25〜1)。省略時はどちらも1
- 例: `/?n=1000010000100001-1001000001100000` (2小節)
- 最大256小節 (譜面は画面内のみ描画する仮想化付き)

トップページのエディタにSMファイルの `#NOTES` 以下を貼り付ければ、このURLを自動生成できます。

## 開発

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # プロダクションビルド
```

Next.js (App Router) 製。OGP画像は `/og` ルートで `next/og` (satori) により動的生成しています。日本語タイトルはGoogle Fontsからグリフサブセットを取得して描画します(取得失敗時はASCIIのみ)。

デプロイはVercelを想定していますが、Node.jsが動く環境ならどこでも動きます。本番URLを `NEXT_PUBLIC_SITE_URL` に設定するとOGPの絶対URLが正しくなります。
